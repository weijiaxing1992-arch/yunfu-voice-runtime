# RustSwitch 源码导航

本目录提供主工程、独立 ASR 候选、诊断补丁和设计参考。完整产品范围见[项目说明](../01-项目说明.md)，开发流程见[贡献指南](../CONTRIBUTING.md)。

| 目录 | 内容 | 使用方式 |
| --- | --- | --- |
| [main](main) | Go 控制面、Rust 媒体、C 原生适配、后台、配置与测试 | 默认开发入口；`main` 在这里是目录名。 |
| [asr-candidate](asr-candidate) | ASR1、模拟服务、重采样和生命周期约束的候选实现 | 独立构建与验证，尚未合入主工程；不包含真实识别模型。 |
| [patches](patches) | 已完成定向测试的压测诊断补丁及后续工作稿 | 根据各自清单选择版本，合入前重新检查适用性与受影响用例。 |
| [design-reference](design-reference) | ASR 协议夹具和设计阶段材料 | 用于理解与复现设计，验收范围以其收据为准。 |

## 构建入口

固定预览源码可从仓库根目录通过 `delivery-tools/build_source.py` 离线构建。该脚本强制校验 `source/*-manifest.json`，只接受对应的未修改源码快照；输出目录必须在仓库之外且尚不存在。完整步骤与平台条件见[快速开始](../QUICKSTART.md)。

修改源码后，使用对应工程的 Go、Cargo 或 Makefile 开发入口，并记录实际执行的检查。当前两套工程的功能文档门禁仍有已知阻塞，详见[验证状态](../08-当前能力与验证状态.md)；不要通过修改历史证据来消除门禁错误。

## 工程内目录

| 路径（相对具体工程） | 职责 |
| --- | --- |
| `control/` | Go 程序、呼叫控制、信令、管理后台、测试与观测。 |
| `media/` | Rust 媒体进程、RTP/RTCP、会话与实时音频。 |
| `native/` | C ABI 头文件、插件示例及可选音频后端。 |
| `config/` | 本地示例和部署目标配置。 |
| `tests/`、`tools/` | 回归、压测、采样和文档工具。 |
| `docs/` | 对应工程版本的接口、架构与历史验证资料。 |

工程内原文与测试收据保留其版本语境。当前公共说明、组件版本、候选范围和历史状态的解释见[文档中心](../DOCUMENTATION.md)。原始源码清单与候选差异用于版本追溯，不代表全部功能已通过验收。

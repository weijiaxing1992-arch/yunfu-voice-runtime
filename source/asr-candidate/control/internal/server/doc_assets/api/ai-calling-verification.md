# AI电话能力复核记录

当前原版与候选的有限IVR成对测试有3项通过；独立的26个协议回归探针有21项限定通过、3项真实差异，另有身份和目录观测。完整FreeSWITCH兼容、所有通信协议与生产容量均未认证。

## 三应用的真实成对结果

| 应用 | 原版与候选共同实际结果 | 通过范围 |
|---|---|---|
| set | customer=中文客户；Application-Response=_none_ | 单通道设置变量及关联执行完成 |
| unset | customer返回_undef_；Application-Response=_none_ | 清除上述变量及关联执行完成 |
| read | digits=12，read_result=success，read_terminator_used=#；Application-Response=_none_ | silence正常收号及终止符 |

原版为FreeSWITCH 1.11.3的9197 answer+park，候选为明确配置的9197直接本地A腿。两端使用同一份冻结探针，接通后持续发送20 ms PCMU静音和真实RFC4733按键1、2、#。每键三个重复结束包只形成一个DTMF事件，事件时长480，核对了同一通道、唯一Application-UUID和执行开始/完成字段；候选呼叫归零且进程正常回收。

## 与26个协议探针分别展示

26个探针验证ESL与SIP的指定请求、事件与边界；它们与上述三项IVR应用属于独立测试集合。版本身份、API目录枚举也单独记录。SIP能力声明的三个差异继续保留，不通过发布尚未实现的能力来消除差异。当前对照总条目为3983，完整合同通过数仍为0。

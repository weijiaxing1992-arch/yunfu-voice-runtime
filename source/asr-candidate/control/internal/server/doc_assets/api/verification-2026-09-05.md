# 稳定性优化验证记录 · 2026-09-05

对应文档 1.2.0、应用 0.3.0。本记录汇总本轮已执行验证；运行环境为 macOS arm64、本机回环，Go 工具链实报 go1.27.1。Linux amd64 控制程序交叉编译成功，仅证明编译和产物格式，尚未在 Linux 上运行。

## 通话与故障回归

| 验证 | 实际结果 | 边界 |
|---|---|---|
| Go 全包竞态检测 | 通过 | 覆盖控制、管理、媒体监管、信令、日志、配置与发生器；未变更包可使用测试缓存 |
| Go 静态检查 | 通过 | 不替代真实运行与原版差分 |
| Rust 单元测试 | 14 项通过 | 覆盖接收预算、冷却调度、控制输出及既有媒体部件 |
| Rust 独立子进程故障 | 1 项通过 | 不读取 stdout，验证限时退出和端口释放 |
| Rust clippy / 格式 | 通过 | 本机目标检查，未执行 Linux epoll/recvmmsg |
| 普通 UDP 真实通话 | 17 项全部通过，17.434 秒 | 本机双腿 SIP、RTP、RTCP、DTMF 与故障注入 |
| connected UDP 真实通话 | 17 项全部通过，17.452 秒 | 同组场景使用固定对端 socket |
| G.711 C ABI 示例 | 通过 | ABI 1、160 样本，最大绝对误差 501；不是完整转码功能验收 |

真实通话包括连续 183 后最终 200 使用最终媒体地址、取消后迟到应答清理、缺少 ACK 回收、端口复用拒绝旧来源、分片故障及另一分片持续转发、正常排空、保护策略调整保留现有通话。反复建拆以后台目录和 16 通暖机后取得基线，再执行 16 通并静置超过采样周期；检查活跃/接通/媒体资源归零及协程、线程没有按通话数遗留。暖机是为了排除 Go 首轮 GC 的固定后台工作者，判定上限未扩大。

定向回归另外覆盖：1000 次同通话媒体更新只执行首个和最终目标；万次媒体提交受固定队列和一个在途任务限制；错配成功响应、释放契约失败及卡住 RPC；管理重请求预算；20 个成功与错误响应路径在解锁后写入；真实慢 XML 响应期间状态和排空仍可执行。

## 页面测试作业实测

| 场景 | 建立通话 | 实际发送 / 唯一收到 | 未收到 | 清理 |
|---|---|---|---|---|
| PCMU 单路、3 秒 | 1 / 1 | 300 / 300 | 0 | 专属进程、端口、目录全部释放 |
| PCMU 500 并发、100 CPS、10 秒 | 500 / 500 | 499,952 / 499,952 | 0 | 专属进程、端口、目录全部释放 |
| 媒体阶段主动停止 | 已观察到媒体阶段 | 停止任务不作为容量通过项 | 不作完整负载结论 | 全部清理，报告可下载 |

500 并发名义负载为 500,000 包，实际发送比例为 99.9904%，发生器写错误为 0。并未把名义包数当作真实发送；主服务的配置版本、有效配置及保护策略在作业前后保持一致。创建幂等重试、参数冲突、JSON/类型/CSRF 校验均通过。

这些短时结果只证明当前本机回环场景。更长作业的实际结果可在后台「压力与电话测试」中查看；任务历史保存在内存，重启会清空，应下载报告留存。没有从 500 并发外推一万路、外网通话或无限时长无泄漏。

## 接口、页面与完整审计

OpenAPI 3.1 校验通过，25 个 HTTP 操作、57 个数据模型与实际路由对应；新增 controller 状态及实际测试报告均经过模型验证。发布文件、清单 SHA-256 和 ZIP 内容逐一核对。页面脚本语法通过，浏览器完整模块表包含 145 行、业务表包含 35 行，能够查看遗漏的 `mod_com_g729` 构建目录。

FreeSWITCH 审计固定为 1.11.3 及提交 `ef32e205295e29f034f1453ad245ba5efb07b94a`：核对 712 份选定参考源码、538 个注册点、完整树的 144 个模块目录和 1 个 SDK 目录。5 项静态反例/烟测通过。详细范围与每项差距见[完整功能审计](feature-audit.md)。

**原版 FreeSWITCH 动态成对用例执行数仍为 0；无感替换、全模块兼容、Linux 万路及“全面超越”均未认证。** 录音、会议、ESL、XML 执行、完整 Sofia 注册鉴权、转码与在线状态接管等主要缺口必须分别实现并取得运行证据。

## 本轮新增与修复

| 层次 | 实际能力 | 主要检查 |
|---|---|---|
| 线路注册 | 固定上游 REGISTER、Digest 401/407、刷新、423 期限调整、失败退避与注销 | UDP/TCP/TLS 真实注册及 64 包双向 Rust RTP；认证错误、重试循环、超时和注销 |
| 呼叫 | INVITE 挑战 ACK 与新事务重试；精确本地号码自动应答 | 取消与迟到挑战、双腿独立事务、本地仅 A 腿、无 ACK 释放、未命中号码仍走上游 |
| 实时按键 | RFC4733 结束去重、缺结束失败；显式 SIP INFO 模式；DTMF 事件 | 原始包仍透传，业务按键仅一次；来源与载荷校验；INFO 大小写统一且不混入 RTP 按键 |
| IVR | 有界 `sendmsg execute` 的 `set / unset / read / playback` 子集 | 实际变量、收号、超时、音调、提示音打断、挂机取消、开始和完成事件 |
| 媒体 | PCMU/PCMA 单频提示音及桥接恢复、独立按键事件缓冲 | 独立解码核对真实波形；反向语音和双方按键继续；迟到或发送失败显式失败 |
| 管理后台 | 任务详情失效恢复、服务重启旧令牌有界刷新、注册状态与本地接听配置 | 不刷新页面清理旧任务选择，保留未提交参数；随后测试小电话成功 |
| 接口契约 | OpenAPI 输入/输出均收录新增 SIP 配置，补齐 4 个媒体操作 | 真实媒体回复符合 JSON Schema；不能分成 20ms 帧的提示音时长被机器模型拒绝 |

新增实现与关键状态机均有中文注释，参数与限制见 [AI 呼叫总览](ai-calling-reference.md)、[线路注册](trunk-registration.md)、[IVR](ivr-reference.md) 和 [媒体交互](media-interaction.md)。

## 压测页面读取失败与实测

旧页在服务重启或历史淘汰后继续查询旧任务详情，会重复报读取失败并保留错误的运行锁。现在以成功取得的任务目录确认记录是否存在；失效时自动恢复选择，详情临时错误与服务整体连通性分别显示。进程令牌变化时只根据服务明确的刷新提示重试一次原请求。

在本次真实页面验收中，500 路以 100 CPS 建立并保持 10 秒：发送 500000 包、唯一接收 500000 包，双向每路各 500 包，无缺包、重复、发生器写入错误或拆线失败，全部资源清理完成。随后保持页面打开重启服务，旧记录自动清除，表单中的 500 路、75 CPS、12 秒草稿保留；不刷新页面再次拨号成功，2 秒双向发送/接收均为 200 包。[可公开的实际测量](testlab-verification-v1.6.json)保留任务号、结果与清理状态。

以上是 macOS 同机 PCMU 透传与页面恢复检查；不是 5000 路、万路、完整 AI 对话组合或原版性能对比。上轮 1.5 的 5000 路失败和 1.4 的历史成功继续保留，本轮不沿用旧容量绿色。物理 Linux 服务器和业务流量环境仍待提供。

稳定性优化验证记录 · 2026-09-05

对应文档 1.2.0、应用 0.3.0。本记录汇总本轮已执行验证；运行环境为 macOS arm64、本机回环，Go 工具链实报 go1.27.1。Linux amd64 控制程序交叉编译成功，仅证明编译和产物格式，尚未在 Linux 上运行。

真实通话包括连续 183 后最终 200 使用最终媒体地址、取消后迟到应答清理、缺少 ACK 回收、端口复用拒绝旧来源、分片故障及另一分片持续转发、正常排空、保护策略调整保留现有通话。反复建拆以后台目录和 16 通暖机后取得基线，再执行 16 通并静置超过采样周期；检查活跃/接通/媒体资源归零及协程、线程没有按通话数遗留。暖机是为了排除 Go 首轮 GC 的固定后台工作者，判定上限未扩大。

定向回归另外覆盖：1000 次同通话媒体更新只执行首个和最终目标；万次媒体提交受固定队列和一个在途任务限制；错配成功响应、释放契约失败及卡住 RPC；管理重请求预算；20 个成功与错误响应路径在解锁后写入；真实慢 XML 响应期间状态和排空仍可执行。

接口、页面与完整审计

OpenAPI 3.1 校验通过，25 个 HTTP 操作、57 个数据模型与实际路由对应；新增 controller 状态及实际测试报告均经过模型验证。发布文件、清单 SHA-256 和 ZIP 内容逐一核对。页面脚本语法通过，浏览器完整模块表包含 145 行、业务表包含 35 行，能够查看遗漏的 mod_com_g729 构建目录。

FreeSWITCH 审计固定为 1.11.3 及提交 ef32e205295e29f034f1453ad245ba5efb07b94a：核对 712 份选定参考源码、538 个注册点、完整树的 144 个模块目录和 1 个 SDK 目录。5 项静态反例/烟测通过。详细范围与每项差距见完整功能审计。

原版 FreeSWITCH 动态成对用例执行数仍为 0；无感替换、全模块兼容、Linux 万路及“全面超越”均未认证。 录音、会议、ESL、XML 执行、完整 Sofia 注册鉴权、转码与在线状态接管等主要缺口必须分别实现并取得运行证据。

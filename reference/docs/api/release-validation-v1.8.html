新增实现是 uuid_dump 与四个生命周期事件，共5项；其余7项是既有3个通道事件与4个UUID API新增独立验收映射，没有冒充本轮新实现。12项均只授予表内子集通过，不修改完整契约通过标志。

具体修复

  • uuid_dump 在真实通道主循环按UUID定位，支持txt/plain/JSON/XML、未知格式回退、双腿变量隔离、中文名称和值、结束后查无。依据原版实测修正plain方括号和百分号规则；非法XML名称及超预算请求明确失败。
  • 放音 START/STOP 依据媒体回执发布；文件缺失无伪开始，按键和API打断确认停音后完成，挂机与worker故障等待媒体释放。乱序回执不会造成完成后迟到开始。
  • park 实际进入／离开执行槽时发 PARK/UNPARK，并保持每腿身份和完成顺序。
  • 媒体故障重试采用100/200/400/800/1000毫秒上限退避和0–36毫秒错峰；每腿单个在途RPC、每轮最多256项推进、硬期限不续，避免集中高频重试。

发布后500路短时回归

已发布服务运行小电话、停止清理和500路压力测试：500路全部接通，持续10秒双向媒体，标称／实际发送／唯一收到均为500000包，未收到0包、发生器写错误0。115次状态读取全部成功，最长约8.05毫秒；测试停止、资源回收和报告读取均通过，原配置revision=10与峰值策略保持不变。

这是本机隔离实例的短时SIP/G.711媒体回归，不包含5000路、转码／会议／录音组合或原版成对性能比较，因此不改变容量条目的失败状态。测试在第一次1.8发布上运行，随后只将该实测记录内嵌文档，功能源码、Rust媒体和发生器均未改变。查看实际测试摘要。

仍未闭合的范围

当前仍有2846条未实现入口、3918条无当前本地执行证据，属于不同维度，不能相加。完整清单保留全部3985个ID、优先级、下一步动作、剩余差异和文档位置，绿色条目的完整契约缺口也保留。

  • 本次原版活动通道快照有138个JSON字段，候选单腿夹具有12个字段；其余126个原版字段未齐全。原版完整状态机、caller profile、codec和计费变量仍待逐项实现。
  • 文件loading到下一次查询之间立即挂机的短窗口，尚无持久媒体事件日志证明开始；不能保证全部原版事件完备性。完整事件字段、transfer退出park和恢复执行等路径仍待补。
  • 注册服务器／位置数据库、多网关、originate、转接、完整菜单XML、出站ESL、实时ASR/LLM/TTS流、录音、会议、WebRTC/ICE/DTLS/SRTP、全部原模块宿主和C ABI均未因本轮通过而获得认证。
  • 本轮没有5000路组合容量新通过证据；原容量失败仍显示红色。历史5000路发生器供给不足和写错误尚未获得当前完整门禁通过；单路对照及短时本地测试不能替代5000/10000路Linux验收。

1.13：本地 A 腿持续收音与过期语音拒绝

本批围绕 Voice Agent 上行基础实现：将真实对端 G.711 音频从 Rust 媒体图送到有界 Go 接收 SDK，保留来源、缺失、PLC、CN、辅助事件及生命周期信息。本文档包为1.13；实际安装版本须以 GET /v1/docs 和部署回执核对，不能从源码版本推断服务已经更新。完整接口见 RX 收音合同。

新增接口是内部 JSON 控制、FD4 RXS2 和 Go SDK，不增加 HTTP 路由，也不是 FreeSWITCH 同名应用或外部 ASR 服务。原有 SIP、ESL、XML、播放和按键兼容继续按原始对照 ID 维护。真实 ASR/TTS 供应商、实时分支重采样、VAD、双轨录音和物理 Linux 容量仍未完成。

本轮修复的实际问题

系统 socket 中的音频可能在接收进程暂停时滞留；仅检查 Go 内部队列年龄会把恢复读取的旧语音当成新输入。RXS2 为每条普通记录携带共享单调时钟域、观察时间下界和固定 100ms 期限。重试、跨进程入队、同 ID 查询均不续期。Go 入队、SDK Read 和 Server 交付前分别复查，过期、时钟不一致和慢消费明确报错并对账，不充当用户沉默。

Rust 使用固定 8 槽订阅队列和独立 FD4，控制与下行 FD3 分离。静默订阅遇到共享出口故障也会正确失败，已完成终态不被后续故障重写。不支持共享时钟的平台不宣告 RX 能力。保证限于实际检查点；操作系统可能在检查与发送、函数返回之间抢占，调用方继续入队或写供应商前仍须复查帧期限。

Server 只有在真实本地 A 腿完成正确 ACK、取得 G.711 local 分配并核对健康同代 Worker 后授权收音。固定 4 个控制执行者、有界 64 个在途请求，不为每帧创建协程或访问通话映射。挂机先撤销读取，再由真实 Release 或所属 Worker 代次终止确认退休；取消和未知回执保留清理句柄。

真实 SIP 每例等待原有32秒协议定时器清理，不手工清除定时器来生成零值。Server.Run 先正常排空后关闭；媒体池沿用现有进程关闭机制，不将其描述为 Rust 进程自然退出认证。

回归、兼容状态与下一步

当前生成目录保留全部3994个上版ID，新增5个内部RX合同，共3999条；实现口径为仅导出882、自有入口19、内部合同23、未实现2844、完整契约待验证178、部分实现53。独立运行口径为限定本地通过82、未运行3916、历史容量失败1；相对已发布1.12的77项，新增5项、撤回0。内部SDK没有增加FreeSWITCH同名应用，不能把这5项计算为完整原版模块兼容。

新增条目为 key-ipc-rx-subscribe、key-ipc-rx-status、key-ipc-rx-unsubscribe、key-ipc-rx-stream、key-api-rx-sdk，最后一项同样是内部Go SDK。41项RX验证器反例检查通过，真实12子例/8960解码样本由发布器独立重放，绑定715个相关源码/依赖/模板文件及4个实际Go测试/Rust二进制。独立复核修复了完整RTP展开位置、有效位、SIP对话tag和源码集合漏查，原始证据没有重写。

两种UDP模式的旧协议、PCM下行、转码回归已完成。固定FreeSWITCH 1.11.3在隔离Linux虚拟机完成26探针对测：21项限定通过、1项身份观察、1项目录观察，UDP/TCP/TLS的3项OPTIONS能力头差异保留。243个原版参考文件、1135个候选与执行输入前后不变；清理进程、端口并正常关闭虚拟机。候选运行器退出2表示有差异，不作全过解释；这批探针不执行Linux RX媒体路径。

发布证据工具87项检查通过（其中RX41项、运行证据18项），目录进度9项、成对证据47项通过。新目录的82项限定本地通过与原版21项子场景分别统计；3999项完整合同认证仍为0。安装后还须实际核对HTTP文档版本、原始文件摘要与页面，部署结果另存回执。

此前后台总览已区分主服务与隔离压力任务，运行时显示实际活跃/接通、包数、资源与采样峰值，完成态保留累计和曲线。已发布1.12的100路60秒实际600000包联调结果保留；本批未重跑或扩大为5000/10000。当前作业历史是有限内存记录，服务重启后清空；读取失败与无历史是两种状态。

下一阶段将本地 RX 接入有界流式识别适配器，按 ASR 分支需要转换16k，补充 VAD/语音打断及异步双轨录音。完整 AI 链路、等价 FreeSWITCH 性能基线、72小时混合负载和生产灰度仍须分别验收。

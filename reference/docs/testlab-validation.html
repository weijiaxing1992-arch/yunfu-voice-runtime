压力与电话测试交付记录

验证日期：2026-09-05。页面入口：/#tests。接口合同版本：1.1.0。

已交付功能

  • 压力预设为 500、1,000、2,000、3,000、5,000 路，自定义范围 1–10,000 路。
  • 可设置建立速率、媒体时长、PCMU / PCMA；小电话固定单路，不需要麦克风或真实外部号码。
  • 每次创建专用 Go 控制、Rust 媒体和发生器进程，使用真实 SIP 建立、双向 RTP 核对及拆线。
  • 页面显示任务阶段、实际接通、采样峰值、双向包计数、清理、失败证据与报告下载。
  • 相同创建请求保持幂等，同时只运行一个任务；离页可恢复查看，主动停止及服务退出均清理自己的资源。
  • 隔离端口预检避开业务范围和已占端口；资源不足保留原目标与失败原因，清理未确认时停止受理新增测试。
  • 新增五个测试操作及完整模型进入后台接口文档，并单独记录与 FreeSWITCH 的对应关系。

实测证据

本次环境为 macOS / arm64，10 个逻辑 CPU，同机回环发生器与测试实例。以下结果只描述这些短时间任务。

场景 实际结果
单路 PCMU，3 秒媒体 1/1 建立，双向合计发送 300 包、唯一接收 300 包；清理完成
单路 PCMA，3 秒媒体，由页面发起 1/1 建立，两个方向分别发送/接收 150 包；清理完成
单路媒体阶段主动停止 API 和页面均进入 stopped，已有媒体采样保留，进程、端口及工作目录清理完成
500 路，100 次/秒，3 秒媒体 500/500 建立，事件日志接通峰值 500；发送 149,952 包、唯一接收 149,952 包，负载比例 99.968%，发生器无缺包或写入错误
1,000 路，100 次/秒及 15 次/秒 当前电脑隔离连续端口不足，预检失败，未开始发生媒体，不计作容量通过
5,000 路，由页面发起 预检报告端口不足，原目标保留为 5,000，未采集指标显示“—”，清理完成

所有验收任务均核对了主服务活动配置、版本和峰值策略保持不变。端口自动避让已在实际 500 路任务中排除其他程序占用的 1053 端口，未操作该程序。

自动化及页面检查

Go 全量竞态测试、静态检查通过，控制与发生器可交叉编译为 Linux amd64；交叉编译不等同于 Linux 运行验收。后端边界测试覆盖非法输入、幂等冲突、历史和内存上限、慢客户端下载、清理阶段停止、子进程继承日志管道、FIFO 文件和端口隔离。

浏览器验证包含所有预设和自定义表单、单路发起、媒体阶段离页恢复、主动挂断、完整方向报告、失败状态以及 390 像素宽度下无页面横向溢出。接口文档提供 25 个操作、56 个模型、39 份文档；实际报告与 OpenAPI 模型、在线原文及 ZIP 内容分别校验。

可复现工具和结果解释见 压力与电话测试接口。完整报告可从任务页面下载；当前进程只保留最近 20 份，重启清空。本机结果不构成生产万路、真实网卡、长期运行或 FreeSWITCH 无改动替换认证，目标 Linux 服务器仍待提供。

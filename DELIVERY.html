RustSwitch 项目资料与交付索引

RustSwitch（云蝠 Voice Runtime） 是面向电话呼入、外呼和语音智能体的开源实时语音内核。本索引汇总项目说明、拓扑架构、接口、使用方法、源码、需求与验收资料。

  • 在线阅读：从 项目首页 或下方章节进入。
  • 离线阅读：下载 首个公开预览版 的完整资料 ZIP，解压后打开 index.html，无需联网、登录或启动服务。
  • 开发与体验：先读 快速开始，再根据平台选择源码或运行包。

源码与预编译程序

主工程位于 source/main/，ASR 候选位于 source/asr-candidate/，经过定向验证的补丁与未复验工作稿分别保存。固定依赖及构建脚本随源码提供；基础离线构建复用已有内嵌文档，不执行完整功能发布验收。

运行包 系统范围 关键限制
macOS ARM64 macOS 26+，Apple Silicon 含可选原生动态库，开发构建未做 Developer ID 公证
Linux ARM64 Linux aarch64 静态核心程序，不含 G.722/Opus 可选动态库；候选组合未完成 Linux 整组联调

运行文件通过 Release 附件提供，Git 仓库仅保留其说明、配置、来源与许可。当前没有 Linux x86_64 预编译包。下载校验、启动和目录关系见第 11 章。

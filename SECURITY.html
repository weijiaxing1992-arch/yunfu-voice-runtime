安全报告

当前为开发预览阶段，仅用于受控开发和验收环境。管理后台、SIP、ESL、媒体及原生库边界均应纳入部署审查。

请使用本仓库的 GitHub 私密漏洞报告 提交可复现的安全问题，避免在公开 Issue 中提交真实凭据、号码或音频。如果该入口尚不可用，可先开一个不含漏洞细节的联系请求，由维护者安排私下报告方式。

报告请包含受影响版本、入口、必要条件、最小复现、预期与实际行为、以及脱敏的日志。项目暂未承诺固定修复时限或长期支持周期。

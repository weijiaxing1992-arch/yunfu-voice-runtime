# 公开分发与信息处理说明

本次公开发布包含当前交付材料中的两套源码、候选补丁、设计原型、固定依赖、项目资料、测试工具、历史证据和两个 ARM64 平台编译包。原始本地资料保留不动，公开版本在单独目录生成。

## 文本与证据

个人开发目录在公开文本中替换为 `/workspace/yunfu-voice-runtime` 或 `/home/developer`；历史压测材料的一项实际内网白名单地址替换为文档地址 `192.0.2.160`。测试 fixture、示例密码与文档地址保留，第三方作者版权与联系信息不作匿名化。

`publication-changes.json` 记录公开副本相对于本地交付包的文件哈希变化。根清单与源码清单以公开副本重新生成；原始历史报告内部的旧哈希和结果保留，用于注明历史构建身份。脱敏后的报告不是新的执行证据，不应用其文本哈希直接冒充原报告身份。

源码README的Go依赖说明、当前使用入口和开源许可状态已更新。Linux运行脚本的可选动态库扩展名由`.dylib`修正为`.so`。其余功能状态与门禁失败未被改为通过。

## 预编译文件

编译文件保持既有构建的原始字节，执行文件哈希未变。部分二进制和动态库包含开发机的用户名/构建路径，或者嵌入的历史文档。这些是构建元数据，不是运行凭据。本次没有为清除元数据修改二进制、重签名或把历史测试结果转移到另一个构建。

源码公开副本包含文本说明和证据脱敏变化；预编译程序依然对应原始构建，内嵌文档没有随GitHub开源说明更新。要生成与公开副本一致的内嵌资料，可按QUICKSTART从源码构建；这仍不代表已通过功能发布门禁。

## 分发位置

Git仓库保存完整源材料和运行包说明，实际可执行文件和动态库通过同一标签的GitHub Releases提供。完整资料ZIP同时包含源码与编译包；源代码ZIP和平台ZIP供分开下载。

所附完整性校验只证明分发文件未损坏；历史兼容、容量与供应商接入测试各自保留原范围。源码中故意非法的JSON测试向量不能按普通文档JSON统一判定为错误。

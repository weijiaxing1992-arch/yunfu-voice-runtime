RustSwitch 项目文档中心

本页提供 RustSwitch 的文档导航、版本解释和技术术语，适用于项目评估、应用接入、源码开发及运行维护。项目公开名称为 FreeSWITCH 平替 RustSwitch；历史源码、协议和资料中的“云蝠 Voice Runtime”指同一项目。产品定位是面向语音智能体的实时语音内核，当前发行阶段为开发预览。

文档修订日期：2026-09-08。修订范围与历史记录见更新日志。

核心术语

术语 本项目中的含义
控制面 Go 进程负责的信令、呼叫状态、准入、配置、管理与媒体进程监管。
媒体面 Rust 进程负责的 RTP/RTCP、媒体会话、音频处理与有界队列。
Call / Leg 呼叫及其独立对话腿。双腿桥接需要分别管理两端信令、媒体与释放。
Worker / generation 媒体工作进程及其代次；代次用于防止旧命令操作重启后的新资源。
Guard / CPS 新呼叫准入保护 / 每秒呼叫准入速率；保护阈值是配置，不是已验证的处理容量。
Relay 按已协商规则转发媒体包，不代表媒体经过解码、处理或转码。
Codec processing 实际执行解码、PCM 处理、编码与发送的路径，须独立于转发负载验证。
Sample rate / RTP clock 音频采样率 / RTP 时间戳时钟。G.722 分别为 16 kHz / 8 kHz；Opus 的 RTP 时钟为 48 kHz。
RX / TX 对端进入服务的音频 / 服务发往对端的音频；识别输入与播放输出分开追踪。
Turn 一轮音频交互的身份；用于取消、打断及拒绝过期音频。
ASR / TTS / VAD 语音识别 / 语音合成 / 语音活动检测。内部流协议与模拟服务不等同于真实模型集成。
受理 / 完成 命令被接受 / 操作达到合同规定的终态。客户端须按事件或状态确认实际完成。
Profile 明确线路、编码、并发、CPS、保持时长、功能、音质和资源统计范围的验收配置。

文档维护要求

  1. 接口修改同时更新字段定义、示例、错误处理、FreeSWITCH 对照和相关验收记录，保留原有稳定编号。
  2. 使用仓库内实际存在的相对路径；命令注明执行目录、前置条件和输出位置，凭据使用明确占位符。
  3. 能力描述注明主源码、候选或离线工具范围；性能数字注明目标或实测，并关联环境和证据。
  4. 公开 Markdown 与离线 HTML 同步维护，检查目录、图片、模型锚点、下载路径及文件清单。
  5. 保留历史失败、来源记录和第三方许可原文；新结论通过新增记录与精确版本建立关联。

文档问题通过 GitHub Issues 提交，请附页面路径、版本、问题段落和建议修正。涉及敏感信息时按安全说明处理。

08 当前能力与验证状态

本章说明 RustSwitch（云蝠 Voice Runtime） 的实现范围、验证依据和剩余工作，供技术选型、集成评估与验收使用。公开版本为开发预览，源码分发已经完成；业务功能、兼容性和容量分别按对应证据判断。

如何理解状态

状态 可以得出的结论 不能据此推导的结论
已实现 对应代码、入口或配置处理存在 所有正常、异常和互通场景均通过
有限验证通过 指定快照在记录的平台与用例下通过 后续修改、其他平台或完整产品通过
仅配置导出 可以编辑或生成配置文件 运行时已消费配置并具备对应业务能力
未实现／部分实现 尚缺入口、行为或场景 可无感替换原版同名功能
未验证／证据失效 缺少适用的执行证据，或证据与源码不再匹配 可凭历史绿色状态继续验收

构建通过、配置检查通过、压缩包完整性通过、业务验收通过是不同结论。状态展示应保留这种区分，不用单一百分比代替实际适用范围。

当前工程能力

方向 已提供的工程内容 集成边界与下一步
电话与控制 SIP 呼叫处理、线路配置与注册相关实现、呼叫准入和管理后台 按目标线路验证身份映射、注册周期、完整 originate、转接及 SIP 扩展
核心媒体 Rust 媒体进程、RTP/RTCP 处理、G.711 PCMA/PCMU、PCM 收发相关实现 按真实网络验证丢包、抖动、超时、资源回收和发送尾延迟
交互与迁移 DTMF、播放与收号相关实现，部分 ESL、IVR 与配置对照 逐项核对原版语法、事件顺序和错误语义；同名入口不自动等价
AI 接入候选 ASR1、Unix 客户端、PCM 来源与期限检查、8→16 kHz 重采样、模拟代理 尚未形成真实 ASR/TTS 供应商和完整 Voice Agent 链路
管理与测试 HTTP 管理接口、可视化配置、保护参数、隔离 SIP/媒体测试和压力发生器 小电话是单路模拟测试；页面并发档位不代表已取得相应容量认证
原生音频扩展 C ABI、G.722/Opus 可选后端和相关探针 完整实时音频图、音质及跨平台装载仍需专项验证

具体字段与调用方式见 HTTP 接口、协议与 SDK；逐条差异见 未完成清单。

已记录的 ASR 候选验证

以下结果来自保留的历史收据。本次文档整理没有重新执行这些测试，也没有扩大原断言。

验证 记录结果 证据及适用范围
Go 全包竞态回归 1,471 个通过测试事件，其中 504 个顶层测试；无失败或测试用例跳过 full-review-01；两个无测试包不计为业务用例通过

SIP／Rust／ASR 接入 5 个场景通过 server-real-02；PCMU/PCMA、8/16 kHz、晚订阅、ACK 资格、FINISH/DONE、正常 BYE 与清理
独立样本审计 44 个 RTP 输入含 4 个预订阅包；40 帧进入 ASR；8,960 个输出样本 服务端独立审计；核对 RTP 展开、G.711 解码、重采样、期限与资源
配额回收修复 定向 race 98 项与 vet 通过 无绑定回收收据；仅实际确认无 RX 绑定或退休后释放未知槽

5 个真实 SIP 场景的 BYE 均发生在正常 Finish 后；晚订阅不回放 kind 7，但首个 Decoded 仍有 Boundary 5。这些结果不覆盖所有“挂断／打断／等待 final”组合。首轮因测试 oracle 漏算 Rust 初始展开周期而失败的记录保留，修正后另存重跑收据。

历史绑定报告记录原收据覆盖的 896 个文件在打包时的核对结果。该报告不覆盖收据以外的 Makefile、源文档增量、后续公开处理或未复验工作稿；公开副本的哈希清单用于另外核验分发字节。

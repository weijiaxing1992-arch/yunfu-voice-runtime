# RustSwitch 社区视觉资源

本目录保存项目首页的可编辑矢量图，供中英文首页及离线手册复用。

| 文件 | 用途 |
| --- | --- |
| [hero.svg](hero.svg) | 项目名称、产品定位和技术栈主视觉。 |
| [architecture.svg](architecture.svg) | 控制面、媒体面、原生适配及 AI 接口关系。 |

SVG 为自包含文件，不加载脚本、远程字体或外部图像。架构图使用实线表示主工程已有路径，虚线表示独立候选或待接入能力；连线不代表全部语义已经验收。

修改图示时同步中英文替代文本、图例和正文说明，并在桌面与手机宽度检查可读性。能力范围以[项目首页](../../README.md)和[未完成清单](../../13-项目未完成清单.md)为准，详细图源见[部署拓扑](../../02-项目拓扑图.md)及[软件架构](../../03-软件架构图.md)。

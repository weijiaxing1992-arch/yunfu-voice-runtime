云蝠 Voice Runtime 开源说明

云蝠 Voice Runtime（代码中沿用 RustSwitch 名称）面向电话外呼、呼入与语音智能体。媒体处理采用 Rust，呼叫控制和管理后台采用 Go，通过独立 C ABI 与现有编解码库衔接。项目逐步提供有实际业务价值的 FreeSWITCH 接口兼容。

本次公开的是已有工程、资料、测试依据与缺口清单，供学习、开发、复现和协作。当前发布为开发预览。已有可编译、可运行的实现，同时存在未完成和未通过当前验收的部分。公开源码不表示通过生产验收，也不表示 100% FreeSWITCH 兼容。

当前验证边界

  • 完整对照目录记录 3,999 项声明、接口、配置和验收条目，不等于 3,999 个已实现功能。应同时查看实现状态、证据范围与源码是否仍匹配。
  • 当前资料的发布验收仍有阻塞：主版本文档校验提示 key-api-pcm-stream 绿色证据失效，ASR 候选文档字段字典与机器合同不一致。修复前保留为未通过。
  • 历史测试通过只覆盖相应快照、平台和场景。不能直接推出当前版本的完整 FreeSWITCH 兼容、5,000／10,000 路生产容量或真实语音智能体全链路性能。
  • Linux ARM64 主版本具有限定范围运行记录；候选运行包组合尚未共同运行验收。macOS 原生库的系统要求与核心程序不同，随包 README 明确最低系统版本。
  • 真实 ASR/TTS 服务、完整 Agent 编排、部分通信协议、编解码及传统 PBX 功能仍按未完成清单推进。

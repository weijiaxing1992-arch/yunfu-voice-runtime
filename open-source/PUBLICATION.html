公开分发与版本追踪说明

本说明解释 RustSwitch 公开源码、发行附件、历史证据与后续文档之间的关系。公开版本由独立副本整理，包含主工程、ASR 候选、补丁、设计参考、固定依赖、项目资料、测试工具和两个 ARM64 平台的运行包。

已发布的固定版本

首个开发预览版 v0.1.0-preview.20260908 已公开，绑定提交 54fcd571874d599b10611dc7f38f2a751a433c94。首发的 4,991 个 Git 文件已核对远端路径、Git 对象哈希及权限模式；8 个发行附件已核对名称、大小和 SHA-256。

分发入口 内容 校验与更新方式
Git main 分支 当前社区说明、源码与资料 通过 Git 提交记录后续修改；不沿用旧快照文件数作为当前数量
固定 Git 标签 首个预览版源码树 固定在对应发行提交，用于复现该次源材料
完整资料 ZIP 资料、源码、依赖及两个平台运行文件 按同次 SHA256SUMS.txt 与包内清单校验
源码 ZIP 主工程、候选、补丁、构建工具与依赖 独立的源码分发快照
平台 ZIP 可执行文件、动态库（按平台）、配置、来源与许可 按包内 verify.py 和清单核对解压内容

发行附件保持冻结；后续说明修订不会覆盖其 ZIP、哈希、内嵌文档或原始收据。下载方式与平台要求见 交付说明。GitHub 自动生成的源码归档不包含仅放在平台附件中的运行程序。

内容审查摘要记录 99 个处理文件和 14 个保留构建元数据的文件。首次公开处理差异记录整理阶段的新增或修改类型及前后哈希；其范围按该 JSON 的 scope 解释，不是 main 分支持续更新的完整变更日志。后续变更以 Git 历史和对应版本清单为准。

首次公开整理还修正了源码 README 的 Go 依赖及许可说明，并将 Linux 启动脚本的可选动态库扩展名改为 .so。功能未完成项、文档门禁失败和历史高并发失败记录保持原结论。

历史证据与公开清单

历史收据中的旧源码、二进制和日志哈希保留为当次执行身份。报告文字经公开处理后，其文件哈希会改变；不能用处理后的文本哈希冒充原始收据，也不能把旧测试结果自动绑定到后续源码。

根清单、源码清单和运行包清单分别核验各自公开文件。更新当前 main 的材料时可以生成当前清单，但不得改写旧 Release 的校验值。文件完整性检查说明分发字节是否一致，不证明兼容、音质、容量或供应商接入通过。

预编译程序与内嵌文档

首个预览版的 20 个编译文件保留原构建字节。部分程序和动态库含开发机用户名、构建路径或历史内嵌文档；这些已识别内容属于构建元数据，不是运行凭据。本次没有对二进制做路径替换、重签名或将旧运行证据转移到另一份构建。

delivery-tools/build_source.py 从公开源码执行基础离线编译，复用现有内嵌文档，不会将新的社区说明自动嵌入后台。要更新后台内嵌资料，需先解决对应文档门禁、同步派生资源，再单独构建和验证；直接基础编译不能代替该流程。

因此，GitHub main 上的说明、固定 Release 的离线手册、程序内嵌后台文档可能属于不同快照。集成时以所用源码和接口合同为依据，版本关系见 当前能力与验证状态。

许可与内容追溯

原创材料采用 Apache-2.0，G.722 支持文件和 SpanDSP、FreeSWITCH 模板、Opus、Go/Rust 依赖及运行时分别保留自己的许可。公开处理不重新授权第三方内容。详见 开源说明、许可范围和第三方清单。

内容审查方法、发现和范围限制见 公开内容审查报告。私有原始材料及含本机定位信息的扫描中间文件不作为公共使用入口，公开读者以仓库已分发的摘要、版本和校验文件为准。

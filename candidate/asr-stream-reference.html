云蝠 Voice Runtime：ASR 上行内部接口说明

本文对应 work/voice-runtime-m2-asr/project 中的隔离候选实现。文档尚未嵌入管理后台，主服务没有因此更新。ASR 控制入口是控制项目内部 Go SDK；ASR1 是同机私有代理协议，现有 HTTP 仅新增资源观测字段，没有新增公开的识别启动、送音或结果接口。

目标链路为：正确 ACK 的本地 G.711 通话 → Rust RX 观察 → Go ASR 适配器 → 独立 ASR1 代理 → 业务读取结果。当前独立验收代理执行 PCM 摘要校验，不运行识别模型。

1. 使用范围与前置条件

  • 仅接收本地单腿 A 腿，通话必须已接通、已正确 ACK、已分配媒体且尚未结束或释放；UUID 必须属于当前实际通话。
  • Rust 必须运行 g711 本地处理拓扑，当前健康分片、PID 和代次必须与通话一致，并声明 processed_g711_v1、processed_g711_local_v1、rx_g711_local_v2。
  • 输入只接受 PCMA/PCMU、8 kHz、单声道、20 ms；输出为 8 kHz 或按需转换的 16 kHz、单声道 S16LE、20 ms。其他 codec 的透传/离线编解码能力不能替代这一 ASR 输入条件。
  • 每个 UUID 同时只允许一个起建、活动或等待清理的 ASR 槽。下一次 RX 订阅须遵守原 RX SDK 的递增订阅身份与旧远端终态规则；不能用重试绕过未知清理。
  • 代理必须与 Runtime 使用相同用户、同机共享时钟域。Linux 跨 time namespace 的进程不在此协议支持范围内；远程云供应商须由本机代理转接。

2. 部署配置

以下是完整启动配置中的一个片段，路径需由部署准备：

{
  "asr_stream": {
    "socket_path": "/run/rustswitch-asr/provider.sock",
    "sample_rate": 16000,
    "max_streams": 64
  }
}
字段 JSON 类型 校验与默认语义
asr_stream 对象，可省略 省略关闭；JSON null 也解码为关闭的 nil，响应会省略 nil。空对象不表示关闭。结构对应 config.ASRStream。
socket_path string，必填 规范绝对路径，非根目录，UTF-8 编码最多 100 字节，无 NUL/CR/LF；不能与 pcm_stream.socket_path 相同。
sample_rate integer，可省略 仅 8000/16000；省略或 0 使用 8000。不是 SIP codec 协商参数。
max_streams integer，可省略 省略或 0 使用 min(64, limits.max_calls)；有效值为 1 到 limits.max_calls，包括起建和未知清理。

默认值计算返回独立有效配置，不会改写原始配置。GET /v1/config 的 active/desired 保留原值和省略语义。通过 PUT /v1/config 保存其他设置时，必须保持 asr_stream 对象及其省略状态不变；修改路径、采样率、预算、启用或禁用都会被拒绝，当前返回 HTTP 422。更改需修改部署启动配置并按服务发布流程生效。

静态配置校验不创建或探测代理文件。真正连接前后会核验 socket 的直接父目录为当前用户拥有的 0700 目录，socket 是当前用户拥有的实际 Unix socket，两次目录/socket 身份一致，连接对端 UID 匹配。Runtime 不拥有、不创建、不删除供应商目录和 socket。

3. Go 调用入口与所有权

包路径为 rustswitch/control/internal/server、rustswitch/control/internal/asr。Go 的 internal 可见性限制意味着这是控制项目内部接口，不是可供任意外部程序直接导入的公共 SDK。

func (s *Server) StartASR(ctx context.Context, uuid string, subscriptionID uint64) (*asr.Stream, error)
func (s *Server) ASRSnapshot() ASRStatus

func (s *Stream) Next(ctx context.Context) (Event, error)
func (s *Stream) Finish(ctx context.Context) error
func (s *Stream) Cancel()
func (s *Stream) Snapshot() Snapshot
func (s *Stream) Reap(ctx context.Context) bool
func (s *Stream) Closed() <-chan struct{}
方法 使用约定
Server.StartASR 先预留 UUID/额度，再完成代理握手，最后申请实际授权 RX。UUID 非空且最多 128 UTF-8 字节，最终 HELLO 校验拒绝空白和控制字符；订阅 ID 必须非零。调用者不能覆盖固定 socket 和采样率。
Stream.Next 同时仅一个消费者；并发调用返回 ErrBusy。返回 partial、final 或适配器生成的 partial_invalidated；完整完成后返回 io.EOF。结果交付前再次核对原通话生命周期，取消后的排队结果不能继续交付。
Stream.Finish 提出停止输入意图并等待 FINISH 完整写入；已经在途的完整前缀保留，之后不预留新音频。返回 nil 不表示 DONE、业务 final 或资源清理全部完成，须继续调用 Next。
Stream.Cancel 撤销识别流、关闭网络并拒绝尚未交付的结果；不操作下行 PCM/TTS。已完整交付的历史 completed 状态保留。
Stream.Snapshot 当前流的受锁快照；包含数量、阶段、错误与清理状态，不携带文本/UUID/token。
Stream.Reap 每次最多一次有界 RX 退订或状态查询；同一流防并发重入。Server 管理器自动调用，普通业务无需自行建立清理循环。
Stream.Closed 只证明本流 I/O 协程已退出、网络关闭、RX 实际停止或退休，不证明业务已取完排队 final。
Server.ASRSnapshot 所有 ASR 槽的低基数资源快照；不是识别成功统计。

StartASR 返回非 nil 句柄并同时返回错误，表示网络/RX 可能已获得资源、仍需保留清理身份。Server 自动保留额度并调度清理，调用者也应保留句柄便于取消、观察 Closed 和诊断；不要立即用新订阅覆盖它。返回 nil 才代表启动器没有保留的网络/RX 资源。

Start 的调用上下文只约束起建；起建成功后的流由服务上下文和原通话生命周期约束。Next/Finish 的调用上下文约束该次等待，等待超时不等同于显式取消整个流；不再需要结果时调用 Cancel。正常业务顺序是 Start → 持续 Next → 业务明确结束输入时 Finish → 继续 Next 到 EOF → 读取完成状态。挂断、服务退出或错误路径使用 Cancel 并等待管理器确认清理。

底层独立适配器还提供：

func Start(ctx context.Context, service context.Context, opts Options, acquire Acquire) (*Stream, error)
type Acquire func(context.Context) (Source, error)

Options 为固定的 SocketPath、UUID、SubscriptionID、SampleRate。Source 需要实现 Read、Unsubscribe、Status、Snapshot、LifetimeDone、ConfirmedRetired；生产接线使用真实 Server RXHandle。ConfirmedRetired 不能由服务取消推断，只能使用实际底层退休、已确定任务没有创建绑定、明确未提交或真实全媒体池关闭证据。单元测试注入 Source 不等同于真实 SIP 验收。

4. 状态机与完成标准

starting → streaming → finishing → completed
    └────────┴────────────┴──────→ failed / cancelled
状态 含义
starting 起建阶段；管理器在握手/RX 申请尚未完成时已计入额度。
streaming 已取得输入授权，送音、结果读取和生命周期监控运行中。
finishing 已请求停止输入，或代理已 DONE，仍可能等待 RX/网络关闭或业务取完结果。
completed 无失败；DONE 精确匹配完整提交前缀；没有未结束的开放话语；资源确证关闭；队列和正在交付的结果都已消费完。
failed 协议、来源、网络、超时、队列或其他错误；清理可继续进行。
cancelled 显式取消或通话/服务撤权；清理可继续进行。

completed 表示适配器协议与交付完成，不保证模型识别正确，也不保证所有输入样本都有对应识别文字。DONE 只能确认提交计数，不能代替文本质量或业务语义验收。EOF、输入停止、普通 socket 关闭及服务取消都不能单独产生 completed。

资源关闭与业务交付分别记录：即使 Closed 已关闭、管理器已归还额度，尚未消费的 final 仍可让句柄保持 finishing；通话在此期间结束时，Next 仍拒绝迟到结果。无结果队列、无在途交付、资源关闭和有效 DONE 同时满足，才转 completed。

固定资源预算：每流三个 I/O 协程；所有流共享四个清理执行者；结果队列 8 项；单条文本 4096 UTF-8 字节；来源证明最多 64 个合并区间。只能合并同一话语未读的 partial，不能丢弃 final 后伪装成功。超限明确结束识别流。关闭服务采用先关识别网络、再实际关闭媒体池、最后确认并回收未知 RX 的顺序。

5. 业务结果 Event

以下为内部 Go Event 及其 JSON 标签；这里的 uint64 字段在 Go 默认 JSON 中是整数，不是 ASR1 的十进制字符串。当前没有通过 HTTP 暴露这个结构；外部跨语言接口若另行设计须重新处理 64 位精度。

JSON 标签 Go 类型 含义
type string partial、final、partial_invalidated。
text string，可省略 识别文本或测试代理摘要，最大 4096 字节；不写入指标标签。
coverage string，可省略 complete 或 discontinuous；仅结果携带。
result_sequence uint64 代理结果序号；partial_invalidated 为适配器事件，不伪造代理序号。
utterance_id / revision uint64 话语身份与递增修订；已 final 话语不能修改。
source_generation / source_segment uint64 原 RX 来源与段身份。
first_event_sequence / last_event_sequence uint64 结果所覆盖的实际已完整提交 Decoded 范围，两端都必须能找到来源证明。
start_media_ns / end_media_ns uint64 精确媒体起点和右开终点，来自媒体时间线，不是 UTC。

旧来源或暂停后的结果按 stale 计数，不发布。无法证明的未来来源、错误序号、错误媒体区间、越过已 final 范围或错误修订被拒绝。已知缺口跨越时必须声明 discontinuous。来源暂停/切换会生成 partial_invalidated，使当前开放 partial 失效；业务应撤销对应临时文字。

6. 单流 Snapshot 字段

JSON 字段 类型 含义
state / sample_rate string / uint32 当前阶段、有效输出采样率。
input_finished bool FINISH 已完整写出，不只是调用过 Finish。
provider_done bool 已接收并验证 DONE。
rx_stopped / transport_closed bool RX 有真实停止证据 / 本流网络已关闭。
cleanup_pending / resources_closed bool RX 清理仍未确认 / 全部本流资源真实关闭。
adapter_written_audio_frames / adapter_written_samples uint64 适配器完整写入并记账的 AUDIO 帧/样本。不能代替代理消费量。
adapter_written_markers uint64 完整写入并记账的元数据条数。
provider_acknowledged_samples uint64 有效 DONE 回显的样本数，不是模型成功样本数。
expired_frames / unknown_writes uint64 观察过期计数 / 部分提交结果未知次数。
results_received / results_delivered uint64 通过类型/token 解析后收到的 RESULT 数 / 实际向业务交付的 Event 数；交付数可包括 partial_invalidated，不能直接相减当丢失数。
stale_results uint64 被判旧来源、撤销或取消时舍弃的排队结果累计值。
partial_coalesced / partial_invalidated uint64 未读 partial 被更新合并 / 开放 partial 被撤销次数。
queued_results / provenance_ranges int 当前有界结果数 / 来源证明区间数。
last_event_sequence uint64 完整提交并记账的最近输入事件位置。
error string，可省略 首个错误文本；业务分类应优先使用方法返回的 errors.Is。

7. 错误处理

错误 处理含义
server.ErrASRDisabled 未启用部署配置；不能通过重复请求自动启用。
server.ErrASRClosed 服务停止，不再接纳起建。
server.ErrASRInvalid 无效上下文、UUID 或订阅身份。
server.ErrASRCapacity / ErrASRBusy 总额度耗尽 / 同 UUID 仍占槽；等待真实回收。
server.ErrRXNotEligible 不满足正确 ACK、本地单腿、格式、通话状态或健康同代分片要求。
server.ErrRXSubscribeUnknown / media.ErrRXOutcomeUnknown RX 受理结果未知；保留句柄，由清理器退订/查询。
asr.ErrInvalid 底层参数或本次调用参数无效。
asr.ErrUnavailable 代理不可连接、私有路径/对端身份不符、供应商 ERROR 等。
asr.ErrProtocol 握手、消息、来源证明、结果修订或计数不符。
asr.ErrCancelled 显式取消或通话/服务授权结束。
asr.ErrBusy 同时 Next、资源证明预留或其他受限操作冲突。
asr.ErrInputFailed RX 意外结束、输入失效或终态观察；不会把输入 EOF 当正常识别结束。
asr.ErrSubmissionUnknown 部分写入后失败，无法确知远端处理了多少字节；关闭连接，禁止重播相同 PCM 前缀。
asr.ErrResultOverflow / ErrProvenanceOverflow 固定结果/来源预算不足，明确失败。
asr.ErrProviderTimeout 供应商消息、DONE/PONG 或其他内部期限届满。
context.Canceled / DeadlineExceeded、media.ErrRXExpired 等 可能直接返回的调用/来源/网络错误；以上表格不是穷举封闭枚举。

起建握手不同阶段的网络超时可能归类为 Unavailable 或 Protocol，不能假定所有超时必然返回 ErrProviderTimeout。错误伴随的非空句柄和 Closed/ResourcesClosed 状态决定清理责任，不能只凭错误名称归还额度。

8. ASR1 帧格式

Unix stream 每条完整消息最多 8196 字节，全部二进制整数采用小端序：

整帧偏移 长度 内容
0 4 uint32 length，包含其后 4 字节前缀和正文，不含 length 自身；范围 4..8192。
4 1 kind，1..11。
5 1 version，固定 1。
6 2 reserved，固定 0。
8 length−4 正文；AUDIO 为二进制，其余为 UTF-8 JSON。

JSON 必须精确包含对应模型的全部字段。未知、缺失、重复字段、尾随内容、非法 UTF-8、孤立 UTF-16 代理项、过深嵌套均拒绝。仅 MARKER 的 known_duration_ticks、gap、sid_b64 可以为 null，但字段仍必填。所有 wire.U64 值使用规范十进制字符串（例如 "0"、"18446744073709551615"），禁止数字类型、负号、前导零及指数格式。stream_token 是非零、32 位小写十六进制的每连接随机身份，不是 SIP UUID。

kind 名称 方向与正文
1 HELLO Runtime → 代理，Hello JSON。
2 READY 代理 → Runtime，必须逐字段精确回显 HELLO。
3 AUDIO Runtime → 代理，真实 Decoded 的 112 字节头和 PCM。
4 MARKER Runtime → 代理，PLC/CN/缺口/来源/辅助元数据，无伪造音频。
5 FINISH Runtime → 代理，停止输入后的完整提交前缀。
6 RESULT 代理 → Runtime，partial/final 与精确来源范围。
7 DONE 代理 → Runtime，逐字段精确回显 FINISH。
8 ERROR 代理 → Runtime，stream_token 和 code。
9 CANCEL 格式已定义：stream_token、reason；当前 Stream.Cancel 直接关闭连接，不保证发送此帧。
10 PING Runtime → 代理，stream_token 和十进制字符串 nonce。
11 PONG 代理 → Runtime，匹配当前 PING 的 token/nonce。

8.1 HELLO / READY

字段 固定值或约束
protocol ASR1
stream_token / uuid / subscription_id 连接 token、通话 UUID、非零 U64 订阅 ID
source_rate / target_rate 8000 / 8000 或 16000
channels / format / frame_ms 1 / s16le / 20
clock_domain 1=Linux CLOCK_MONOTONIC；2=Darwin CLOCK_UPTIME_RAW
plc_policy / gap_policy metadata / explicit

READY 不允许重新协商格式或更换任何身份。每次 Start 使用新的随机 token；代理重连不重放旧 PCM 或结果。

8.2 AUDIO 二进制正文

以下偏移相对于正文起点，即整帧偏移 8。20 ms 对应 160 或 320 个 int16 样本。

偏移 类型/长度 字段
0 16 bytes token 原始字节
16 / 24 / 32 u64 event_seq / source_generation / source_segment
40 / 48 u64 完整展开 rtp_sequence / rtp_timestamp
56 / 64 / 72 u64 media_ns / lower_ns / expires_ns
80 / 84 / 88 / 92 u32 ssrc / sample_rate / rtp_clock_rate / filter_delay_ns
96 / 98 / 100 / 102 / 104 u16 flags / clock_domain / sample_count / origin / PCM 字节数
106 6 bytes reserved，全 0
112 320 或 640 bytes 单声道 S16LE PCM

origin 固定 1，仅真实 Decoded 可以产生 AUDIO。rtp_clock_rate 固定 8000，不能随目标 16 kHz 改写。8 kHz 滤波延迟为 0；16 kHz 使用 127 抽头 FIR，filter_delay_ns=3937500。该延迟是滤波器群延迟，不是允许延长的观察期限。来源、新段和实际音频间断清空滤波历史；普通辅助按键元数据不自动切断话音历史。

RTP 完整展开位置包含 Rust 内部初始种子周期：序号 1<<16、时间戳 1<<32，再按原始位置连续展开；接收者须保留完整 64 位值，不截成原始 RTP 低位，不用它当 UTC。

8.3 MARKER 字段与类型

字段组 JSON 字段
身份与类型 stream_token、rx_kind、event_seq、source_generation、source_segment
时钟与期限 clock_domain、lower_ns、expires_ns
原始位置 flags、ssrc、rtp_sequence、rtp_timestamp、media_ns、sample_rate、rtp_clock_rate
年龄 observation_age_ms、arrival_age_ms、deadline_lateness_ms、queue_age_ms
已知事实 known_duration_ticks（U64/null）、cn_applied（bool）、reason、boundary、discarded_packets（U64）
条件内容 gap（对象/null）、sid_b64（string/null）

MARKER 的 sample_rate、rtp_clock_rate 都保留来源的 8000，不因 AUDIO 目标 16 kHz 改写。SID 仅 ComfortNoise 携带，规范 base64、解码 1..480 字节；PLC 只携带已知 160 tick 元数据，不把补偿 PCM 当用户输入。未知时长必须为 null，不能补成 20 ms 静默。

rx_kind：2 HistoryPLC、3 Missing、4 ComfortNoise、5 LocalExpired、6 AuxiliaryExpired、7 SourceBoundary、8 InactiveSuspended、9 ObservationFailed、10 ExportGap、11 End、12 ExportFailed、13 Auxiliary。线格式定义包含终态，但当前适配器遇 9/11/12 会直接失败关闭识别流，不将其转为成功 Finish；不能从格式定义推断终态转发已实现。

flags 的 bit0..9 依次为 SSRC 有效、RTP 时间戳有效、RTP 序号有效、媒体时间有效、有边界、CN 辅助已过期、suspended_after、RTP marker、arrival 已知、deadline 已知。bit7 不代表 known_duration_ticks 有效。未声明有效的位置字段须为 0。

boundary：0 无、1 初始来源、2 SSRC 变化、3 包序重启、4 时间戳重启、5 新段、6 已知源 RTCP BYE；必须与边界有效位一致。迟订阅可从首个完整 Decoded 建立当前来源，不要求重放历史 kind 7；首 Decoded 仍可能携带新段边界 5。

reason 的普通值为 0 无、1 MissingPacket、2 AudioDeadline、3 AuxiliaryDeadline、4 StaleComfortNoise、5 InvalidComfortNoise、6 ToneTimeout、7 DecoderFailure、8 ObservationOverflow、9 ObservationSequenceExhausted、10 JitterBufferLimit、11 LateArrival。

ExportGap 的 gap 必须完整包含 first、last、decoded、plc（均 U64 字符串）和 reasons；reasons 是 1 队列满、2 年龄超时、4 停止/撤销的非零组合。last=event_seq，decoded+plc 不超过区间长度。Gap/End/ExportFailed 是摘要，不带音频期限和来源位置：lower_ns/expires_ns、来源、位置和 flags 等为 0，已知时长为 null。普通观察保留原始 100 ms 期限。

丢弃计数与 CN 事实不能随便组合：来源边界 2/3/4/6 可以携带已丢弃包数；过期/拒收编码包的指定原因允许恰好丢弃一包；观察队列失败只允许在 reason 8/9 继承与原事实一致的边界、丢弃数或 CN 标记。其余混合由严格线格式校验拒绝，不能把辅助丢弃记成音频静默。

8.4 FINISH / DONE、RESULT 与控制消息

FINISH/DONE 的全部字段为 stream_token、last_event_seq、audio_frames、samples、markers；除 token 外均为 U64 字符串。DONE 必须与已完整写出的 FINISH 全等；必须在原绝对结束期限前接收，且没有未结束的开放话语。不能通过断开连接代替 DONE。

RESULT 全部字段为 stream_token、result_seq、utterance_id、revision、source_generation、source_segment、type、text、first_event_seq、last_event_seq、start_media_ns、end_media_ns、coverage。身份/序号/媒体时间均为 U64 字符串；type 仅 partial/final，coverage 仅 complete/discontinuous。result_seq 从 1 严格连续，话语和修订递增，精确媒体范围必须可由实际已完整提交 Decoded 证明。partial_invalidated 是适配器业务事件，不是代理可发送的 RESULT type。

ERROR.code 长 1..128 字节，以小写字母开始，其余只允许小写字母、数字和下划线。错误码不写入指标标签；当前收到合法 ERROR 后对业务归为 ErrUnavailable。CANCEL.reason 最多 128 UTF-8 字节。PONG 必须匹配当前尚未完成的 PING，并在期限内到达；未经请求的 PONG 不被当作有效活性证明。

9. 时间与背压预算

环节 当前固定边界
代理连接与 HELLO/READY 最多 2 秒，调用上下文可更短；路径/对端校验失败关闭。
代理就绪后 RX 申请 独立最多 1 秒；未知回执保留资源身份。
原始观察有效期 expires_ns = lower_ns + 100000000，Rust 首次观察决定，读取、排队、重采样和重试均不续期。
普通 AUDIO/MARKER 写入 每次 syscall 等待不超过剩余原始预算和 20 ms 的较小值；部分进度仍受原始绝对期限约束。
无观察期限的摘要 / 控制消息写入 单条消息固定 20 ms 总期限，部分 Write 不续期。
入站消息 首字节前最多 12 秒；首字节出现后全消息最多 1 秒，逐字节进度不续期。
心跳 约 10 秒输入读取窗口到期时发 PING；PONG 最多 2 秒。
正常结束 首次 Finish 提出起最多 2 秒等待有效 DONE；重复 Finish 不续期。
RX 清理 四个共享 worker，每轮每流至多一次 1 秒退订或查询；失败后轮转其他槽。

代理必须在实际消费前复核同一 clock_domain 和 [lower_ns, expires_ns)。转换或收到一帧不等于它在随后消费时仍有效；检查点与 syscall 不能被描述成原子保证。过期、排队溢出和部分提交未知会明确失败，不通过丢帧后宣称完整识别成功。

10. HTTP 资源观测与 Prometheus

新增的 HTTP 内容只有现有 GET /v1/status 返回中的 asr_stream 对象。禁用时仍返回对象：enabled=false，其余 bool=false、计数/上限=0。旧版本完全没有字段时应显示未知，不能当零。现有 GET /v1/config 的 Config 可含启动原始 asr_stream 配置。

status 字段 类型 Prometheus 指标
enabled / stopping bool rustswitch_asr_enabled / rustswitch_asr_stopping，0/1
max_streams / slots int rustswitch_asr_max_streams / rustswitch_asr_slots
starting / active int rustswitch_asr_starting / rustswitch_asr_active
cleanup_pending int rustswitch_asr_cleanup_pending
rejected_capacity / rejected_uuid uint64 rustswitch_asr_rejected_capacity_total / rustswitch_asr_rejected_uuid_total

Slots=Starting+Active+CleanupPending。正常 Finish 的退订过程也可以暂计入清理；RX 已停但还等代理 final 的连接可以计入 Active。Closed 但清理 worker 尚未移除的槽仍保守计入清理。最后两项为本进程累计拒绝，其他为当前 gauge；现有 /metrics 文本没有 HELP/TYPE 声明，采集方按本字典区分。所有指标没有高基数标签。

上述计数均不是识别成功数，不表示供应商健康或模型质量，不包含已经释放槽但业务仍持有的未读结果，也不与隔离压力测试实例混算。管理后台按已有轮询展示主服务 asr_stream；独立压测应使用子实例自己的观测与收据。

11. FreeSWITCH 对照边界

对照依据为项目已有的固定 FreeSWITCH 1.11.3 源码目录及提交 ef32e205295e29f034f1453ad245ba5efb07b94a；它是可复核的固定参考，不声称实时最新版本。

FreeSWITCH 对照点 当前实现关系 尚不能替代的内容
detect_speech 识别输入/结果的业务目的相近；本批是自有 Go/ASR1 入口 同名拨号计划应用、grammar/参数/暂停恢复/计时器命令及原事件语义，现有对照仍 not_implemented。
play_and_detect_speech 上行 ASR 可作为后续组件 播放与识别组合、按键/打断协调、原应用返回变量和完成语义，现有对照仍 not_implemented。
switch_ivr_detect_speech 及相关 C API 内部分层可作概念对照 不兼容 FreeSWITCH C ABI、对象生命周期、回调和模块装载。
mod_pocketsphinx / MRCP 类供应商接入 需要独立适配与验收 摘要 mock 不能当识别模型或 MRCP 客户端，不能加载这些原版模块。
ESL/fs_cli 识别命令与事件 当前新增 API 不走这些通道 ASR1 不兼容 ESL 报文；本批未新增同名命令、识别事件桥或 XML 配置兼容。
status 和模块统计 自有 HTTP/Prometheus 类比观测 字段、传输和输出不同；仅资源观测已实现，不计算 FreeSWITCH 接口兼容率。

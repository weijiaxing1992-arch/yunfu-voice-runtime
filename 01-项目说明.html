01 项目说明

产品目标

云蝠 Voice Runtime（工程名 RustSwitch）是面向电话呼入、呼出及语音智能体的实时语音内核。技术方向是 Rust 媒体内核、Go 控制面、C/C++ 成熟生态适配。现阶段先打通电话与 AI 媒体闭环，并逐步兼容有实际迁移价值的 FreeSWITCH 接口。

同硬件、同音质和同业务功能下更高并发、更低 CPU/内存，以及 1000/5000/10000 路、72 小时混合负载，是研发和验收目标。当前没有证据支持“100% FreeSWITCH 等价”“万路完整 Agent 已通过”或“任意故障零丢包”。

技术栈与运行形态

层 当前真实实现 关键边界
Go 控制进程 SIP 对话/注册/认证、路由、有限 ESL/IVR、准入、媒体监管、HTTP 后台、日志、压测管理 不是完整 Sofia/PJSIP；没有通用公开外呼 HTTP 或已实现的 ESL originate
Rust 媒体进程 多分片、单写媒体状态、非阻塞 UDP、RTP/RTCP、G.711 图、PCM 下行、RX 观察 Linux 批量接收；macOS 兼容路径；活动会话不跨分片自动迁移
C/C++ 适配 编解码 ABI、G.711 示例、固定 G.722/Opus 原生后端 不能直接装载 FreeSWITCH mod_*.so；原生协议 ABI 为预留
管理界面 HTML/CSS/JavaScript 内嵌在 Go 可执行文件 无单独 Node 服务，无 CDN；管理监听限制在回环地址
数据与工具 JSON 配置、JSONL 事件、管理状态文件、callbench、Python 验收工具 没有已交付的数据库集群、消息总线或 Kubernetes 控制面

control/go.mod 要求 Go 1.23，已固定并 vendor golang.org/x/sys v0.30.0，因此不能描述成“无任何第三方 Go 依赖”。Rust rust-version 为 1.85，依赖由 Cargo.lock 固定；实际构建用支持该工程的 stable 工具链。C 编译器和 Python 3 用于原生示例、构建及验收。

已具备的业务基础

  1. 可信 IPv4 SIP 中继间的 UDP/TCP/TLS 双腿呼叫、单固定上游 REGISTER/Digest 客户端、本地精确号码接听。
  2. 同格式 relay；有限 PCMA/PCMU 双腿处理与本地 A 腿图、提示音/WAV、DTMF 接收/发送与受限 read。
  3. 本机同 UID 的 RVA1 流式 PCM 下行；RXS2 本地 A 腿原生收音；带代次、会话和轮次的旧数据隔离。
  4. 并发/CPS/建立中限制、分片过载保护、排空、资源和生命周期日志、可视化配置与隔离测试。
  5. ASR 候选已完成独立代理协议、按需 8→16 kHz 转换、结果来源校验、取消和清理验证。模拟代理返回 PCM 摘要，真实厂商 ASR/TTS/LLM 尚未形成完整产品闭环。

工程目录与职责

outputs/rustswitch/
  control/cmd/rustswitch/     主控制程序入口
  control/cmd/callbench/      SIP/RTP 流量发生器
  control/internal/server/   呼叫、IVR、注册、管理、压测编排
  control/internal/sip/      受限 SIP/SDP 与可靠传输
  control/internal/esl/      入站 ESL 命令、事件、作业
  control/internal/media/    Rust 进程监管与内部媒体 SDK
  control/internal/config/   启动配置与校验
  control/internal/server/guard.go    峰值保护、令牌桶和建立中限制
  control/internal/journal/  生命周期事件持久化
  control/internal/server/web/        内嵌中文后台
  control/internal/server/doc_assets/ 内嵌文档发布副本
  media/src/media/           worker、端口、RTP、实时图、PCM/RX
  media/src/audio/           离线 AudioFrame、编解码、重采样
  native/include/            编解码和协议适配 ABI
  native/audio/              可选原生后端构建与许可
  config/                    本地与 Linux 目标配置示例
  deploy/                    systemd 服务模板
  tests/、tools/             真实通话、故障、压测和文档验收
  docs/                      接口、对照、架构、验收和历史记录

峰值保护与呼叫编排同属 server 包。候选另含 control/internal/asr 与 control/cmd/asr-mock，不包含在主目录基线中。
